# Wordigo Node.js Backend Application

## SE4030 – Secure Software Development Assignment

This repository contains the secured version of a previously developed Wordigo Node.js backend application. The project focuses on identifying and mitigating security vulnerabilities while implementing Google OAuth authentication as an additional authentication method.

# Project Overview

The objective of this assignment is to improve the security of an existing AF Backend Node.js backend application by identifying and fixing security vulnerabilities based on secure software development practices. Additionally, Google OAuth 2.0 authentication has been implemented as a new feature.

Google OAuth 2.0 authentication has been integrated into the application to provide secure third-party authentication.

### Features

- Google Sign-In
- OAuth 2.0 Authorization Flow
- JWT-based authenticated sessions
- Secure authentication alongside the existing login system
